## zh-CN

通过通用 AgentProvider 将本地 Runtime 事件接入 `useXChat`，同时消费消息投影和完整 `agentState`。可切换正常与失败场景，运行中可取消请求。

## en-US

Connect local Runtime events to `useXChat` through a generic AgentProvider and consume both projected messages and the complete `agentState`. Switch between successful and failed runs, or cancel a run while it is active.
