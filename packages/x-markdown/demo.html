🎬 XMarkdown — animateInsideComponents 效果演示

模拟 Markdown 流式渲染 + 打字机动画。自定义标签 <answer> 内的文字能否有动画，取决于开关。

❌ 默认行为 animateInsideComponents: false

自定义组件 <answer> 内部的文字 没有 打字机动画，直接显示。

⬆️ 注意 "42" 和 "北京" 直接显示，没有淡入效果

✅ 新功能 animateInsideComponents: true

自定义组件 <answer> 内部的文字 也有 打字机动画，逐字淡入。

⬆️ "42" 和 "北京" 也有绿色闪烁的淡入动画

绿色闪动 = 有动画 (AnimationText) 无效果 = 无动画 (静态文本)
粉色边框 = 自定义标签 <answer> 内部文字
